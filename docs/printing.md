# Printing

## Печатные формы

Из заказа генерируются две формы. Обе формируются на клиенте (в Tauri WebView) и отправляются на системный принтер через browser print API или Tauri print plugin.

### 1. Квитанция для клиента

**Назначение:** выдаётся клиенту при приёме заказа или оплате.

**Содержание:**
- Название компании / логотип (настраивается)
- Номер заказа
- Дата
- Имя клиента, телефон
- Таблица позиций: описание, кол-во, цена за ед., сумма
- Итого
- Оплачено / Остаток
- Ориентировочная дата готовности (если указана)
- Подпись оператора (линия)

**Формат:** A5 или половина A4 (настраиваемо).

### 2. Производственный лист (наряд)

**Назначение:** используется в производстве для сборки заказа.

**Содержание:**
- Номер заказа
- Дата приёма
- Имя клиента
- Для каждой позиции типа `book`:
  - Формат
  - Количество разворотов
  - Материал блока
  - Тип и материал обложки
  - Ламинация
  - Extras
  - Количество экземпляров
- Для каждой позиции типа `print`:
  - Формат
  - Материал
  - Отделка
  - Количество
- Позиции типа `service` и `extra` — строкой с описанием
- Примечания к заказу

**Формат:** A4.

## Реализация

- Формы рендерятся как HTML-шаблоны в отдельном скрытом окне / iframe.
- Печать через `window.print()` или Tauri print command.
- Никакой генерации PDF на сервере — всё локально.

## Assumption

- В MVP кастомизация шаблонов не требуется (только название компании / логотип в настройках).
- Термопринтер для чеков не поддерживается в MVP (обычный A4/A5 принтер).
