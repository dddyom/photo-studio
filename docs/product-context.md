# Product Context

## What it is

Desktop-приложение для небольшого семейного бизнеса: печать фотографий и сборка школьных фотоальбомов.

## Users

2–3 оператора, работающие преимущественно на одном компьютере (Windows). Пользователи не технические — интерфейс должен быть простым и очевидным.

## Core problems solved

1. **Учёт заказов**: приём, отслеживание статуса производства, оплаты и выдачи.
2. **Ценообразование**: автоматический расчёт стоимости по прайсам с учётом параметров изделия.
3. **Печатные формы**: квитанция для клиента и производственный лист.
4. **Финансовый учёт**: журнал денежных операций, баланс счетов, расчёты с поставщиками и партнёрами, распределение прибыли.

## Non-goals (MVP)

- Складской учёт остатков материалов.
- Личный кабинет клиента / онлайн-заказ.
- Синхронизация между компьютерами / облако.
- Мобильная версия.

## Key principles

- **Local-first**: всё работает оффлайн, данные в SQLite на локальном диске.
- **Простота**: минимум абстракций, UI по существу.
- **Прозрачность финансов**: журнал событий — единственный источник правды для балансов.
