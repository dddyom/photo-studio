# Администрирование прайсов и справочников

## Программы ценообразования

Программа ценообразования — именованный набор правил расчёта цен. Каждому клиенту можно назначить программу по умолчанию (`default_pricing_program_id`), которая автоматически подставляется при создании заказа.

### CRUD

| Операция | Backend команда | Endpoint |
|----------|----------------|----------|
| Список | `list_pricing_programs` | Все программы с `rules_count`, `clients_count` |
| Создание | `create_pricing_program` | `{ name }` |
| Обновление | `update_pricing_program` | `{ name?, is_active? }` |

### Защита при деактивации

Нельзя деактивировать программу, если существуют активные заказы (production_status не `closed`/`cancelled`), использующие эту программу. Backend вернёт ошибку с количеством активных заказов.

## Правила ценообразования

Каждое правило привязано к программе и определяет формулу расчёта для конкретного типа позиции.

### Внутреннее представление

Правила хранятся с `match_params` и `price_formula` как JSON. **Пользователь не вводит JSON вручную** — UI собирает JSON автоматически из типизированных форм. JSON доступен только в debug-секции формы.

```json
{
  "id": 1,
  "pricing_program_id": 1,
  "item_kind": "book",
  "match_params": "{\"component\":\"block\",\"assembly_kind\":\"plastic\",\"format\":\"20x30\"}",
  "price_formula": "{\"type\":\"fixed\",\"price\":600}",
  "is_active": true
}
```

### Типы формул

#### `fixed` — фиксированная цена
```json
{ "type": "fixed", "price": 5000 }
```
`unit_price = price`, `total = price * qty`

#### `base_plus_per_unit` — база + за единицу
```json
{
  "type": "base_plus_per_unit",
  "base": 3000,
  "per_unit": 200,
  "unit_field": "spread_count"
}
```
`unit_price = base + per_unit * spec[unit_field]`, `total = unit_price * qty`

#### `book_composite` — составная цена книги (блок + обложка + опции)

Для книг с указанным `assembly_kind` цена рассчитывается как сумма компонентов:

```
unit_price = block_price × spread_count + cover_price + Σ cover_option_prices
```

Каждый компонент ищется отдельным правилом по `match_params`:
- **Блок**: `{"component": "block", "assembly_kind": "plastic", "format": "20x30"}` — формула `fixed`
- **Обложка**: `{"component": "cover", "cover_family": "eco_leather", "format": "20x30"}` — формула `fixed`
- **Опции обложки**: `{"component": "cover_option", "option_name": "Гравировка"}` — формула `fixed`

Если `assembly_kind` не указан — используется legacy-расчёт через обычный подбор правила.

### Алгоритм подбора правила

1. Из всех активных правил программы фильтруются по `item_kind`
2. Для каждого правила проверяется, что все ключи из `match_params` совпадают с соответствующими полями спецификации заказа
3. Побеждает правило с наибольшей специфичностью (количество ключей в `match_params`)
4. Если подходящих правил нет — ошибка

### CRUD правил

| Операция | Команда | Примечание |
|----------|---------|------------|
| Список | `list_pricing_rules(pricing_program_id)` | Все правила программы |
| Создание | `create_pricing_rule` | Валидация JSON и формулы |
| Обновление | `update_pricing_rule` | Частичное обновление |
| Удаление | `delete_pricing_rule` | Жёсткое удаление |

### Предпросмотр цены

Команда `preview_price` позволяет рассчитать цену без создания заказа:

```json
{
  "pricing_program_id": 1,
  "item_kind": "book",
  "spec_json": "{\"format\":\"20x20\",\"spread_count\":10}",
  "qty": 2
}
```

Возвращает `{ unit_price, total_price, breakdown_json }`.

## UI: Типизированные формы правил

### Принцип работы

Вместо ручного ввода JSON пользователь:
1. Нажимает «+ Правило»
2. Выбирает категорию правила из визуального списка
3. Заполняет типизированную форму с понятными полями и селектами
4. Видит preview-описание правила перед сохранением
5. JSON собирается автоматически из формы

### Поддерживаемые категории форм

#### Печать (item_kind = "print")

| Категория | Форма | Единица |
|-----------|-------|---------|
| `lab_print` | Формат (из справочника) + Цена | за шт. |
| `wide_format_print` | Материал (выбор) + Цена | за пог. м |
| `wide_format_lamination` | Тип ламинации (выбор) + Цена | за кв. м |
| `photo_lamination` | Формат + Цена | за шт. |
| `photo_magnet` | Формат + Цена | за шт. |
| `photo_pvc` | Формат + Цена | за шт. |
| `dsp_picture` | Формат + Цена | за шт. |
| `canvas_stretched` | Формат + Цена | за шт. |
| `calendar_double_sided` | Формат + Цена | за шт. |

#### Фотокниги (item_kind = "book")

| Категория | Форма | Единица |
|-----------|-------|---------|
| `book_block` | Тип сборки (plastic/pvc_board) + Формат + Цена | за разворот |
| `book_cover` | Тип обложки (laminated_hard/eco_leather) + Формат + Цена | за книгу |
| `book_cover_option` | Опция (Гравировка/Фото-вставка) + Цена | за книгу |

### Отображение правил

Правила в списке сгруппированы по категориям с человекочитаемыми summary:
- `Лабораторная печать / 10x15 — 50 за шт.`
- `Фото на ПВХ / 30x43 — 1 300 за шт.`
- `Фотокнига — блок/сборка / Пластик (plastic) / 20x30 — 600 за разворот`
- `Фотокнига — обложка / Экокожа / 20x30 — 3 000 за книгу`
- `Фотокнига — опция обложки / Гравировка — 1 000 за книгу`

### JSON в debug-секции

Raw JSON доступен по ссылке «Показать JSON (отладка)» на форме создания/редактирования. Не отображается по умолчанию. Не является основным способом редактирования.

### Редактирование существующих правил

При нажатии «Изм.» на правиле:
- Определяется категория правила из `match_params`
- Открывается типизированная форма с предзаполненными полями
- Пользователь видит текущие значения без JSON
- При сохранении JSON пересобирается из формы

## Справочники (каталоги)

### Общий паттерн

Все справочные таблицы используют soft-деактивацию через поле `is_active`. В выпадающих списках при создании заказа показываются только активные записи. В админке показываются все.

| Таблица | Поля | Примечание |
|---------|------|------------|
| `book_formats` | name, is_active, sort_order | Форматы фотокниг |
| `print_formats` | name, is_active, sort_order | Форматы печати |
| `cover_types` | name, is_active, sort_order | Типы обложек |
| `cover_materials` | name, is_active, sort_order | Материалы обложек |
| `lamination_types` | name, is_active, sort_order | Типы ламинации |
| `materials` | name, category, is_active, sort_order | Материалы (block/print/finishing) |
| `extra_option_types` | name, default_price, is_active, sort_order | Доп. опции с ценой по умолчанию |

### API для каждого справочника

- `list_*` — только активные (для выпадающих списков)
- `list_all_*` — все (для админки)
- `create_*` — создание с валидацией уникальности имени
- `update_*` — частичное обновление (name, is_active, sort_order)

### Материалы

Материалы разделены на категории: `block` (блок книги), `print` (печать), `finishing` (отделка). Категория задаётся при создании и не меняется.

### Доп. опции

У доп. опций есть `default_price` — цена по умолчанию, используемая при добавлении в заказ, если нет правила ценообразования.

## Клиенты

### Расширенные возможности

- **Прайс-программа**: поле `default_pricing_program_id` — при создании заказа автоматически подставляется программа клиента
- **Архивация**: soft-delete через `is_archived`. Архивированные клиенты не показываются по умолчанию, но доступны по переключателю в UI
- **Редактирование**: все поля клиента доступны для редактирования (имя, телефон, email, заметки, прайс-программа)

## UI-страницы

### `/pricing` — Прайсы
- Левая панель: список программ с кнопками активации
- Правая панель: правила выбранной программы, сгруппированные по категориям
- Каждая категория показывает количество правил
- Каждое правило показывает человекочитаемый summary (параметры + цена)
- Кнопки: Вкл/Выкл, Изм., Удл. для каждого правила
- Панель предпросмотра цены

### `/catalogs` — Справочники
- Табы для каждого типа справочника
- Inline-редактирование (клик по названию)
- Кнопки активации/деактивации

## Реальная программа: «Цены»

Демо-программы «Стандарт» и «Оптовый» деактивированы. При первом запуске (seed) создаётся реальная программа **«Цены»** с полным набором правил (~97 правил).

### Категории печати (print)

Правила для `item_kind = "print"` используют поле `category` в `match_params`:

| Категория | Описание | Доп. ключи match_params |
|-----------|----------|------------------------|
| `lab_print` | Лаб. печать фото | `format` |
| `wide_format_print` | Широкоформатная печать | `material` |
| `wide_format_lamination` | Широкоформатная ламинация | `lamination_type` |
| `photo_lamination` | Ламинация фото | `format` |
| `photo_magnet` | Фотомагнит | `format` |
| `photo_pvc` | Фото на ПВХ | `format` |
| `dsp_picture` | Картина ДСП | `format` |
| `canvas_stretched` | Натяжка на подрамник | `format` |
| `calendar_double_sided` | Двусторонний календарь | `format` |

### Составное ценообразование книг

Правила для книг разделены на компоненты (`component` в `match_params`):
- `block` — цена за разворот блока, зависит от `assembly_kind` (plastic, pvc_board) и `format`
- `cover` — фиксированная цена обложки, зависит от `cover_family` (laminated_hard, eco_leather, ...) и `format`
- `cover_option` — фиксированная цена опции обложки (Гравировка, Фото-вставка, ...)

**Формула итоговой цены книги:**
```
block_per_spread × spread_count + cover_price + Σ cover_option_prices
```

### `/clients` — Клиенты
- Таблица с колонками: имя, телефон, email, прайс, дата создания
- Кнопки «Изменить» и «Архив» для каждого клиента
- Форма создания/редактирования с выбором прайс-программы
- Переключатель «Показать архивных»
