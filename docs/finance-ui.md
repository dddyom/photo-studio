# Finance UI

Frontend финансового модуля. Файлы в `src/pages/finance/`.

## Экраны

### 1. Finance Dashboard (`/finance`)

Обзорная страница с тремя секциями:

- **Счета компании** — карточки с балансом каждого активного счёта + итого
- **Ключевые показатели** — долги поставщикам, ссылки на журнал и закрытие периода
- **Расчёты с партнёрами** — сводка по каждому партнёру (вложения, прибыль, draws, баланс)

**Действия:**
- Кнопка «+ Доход» — модал для регистрации прочего дохода
- Кнопка «+ Расход» — модал для регистрации расхода компании
- Кнопка «Перевод» — модал для перевода между счетами

### 2. Transaction Journal (`/finance/transactions`)

Таблица всех финансовых операций с фильтрами:
- По типу транзакции (dropdown)
- По счёту
- По диапазону дат

Колонки: дата, тип, описание, счёт, заказ, сумма (с цветовой индикацией in/out).

### 3. Supplier Debts (`/finance/debts`)

Список обязательств перед поставщиками:
- Фильтр по статусу (все / открытые / оплаченные)
- Карточки с progress bar оплаты
- Кнопка «+ Новый долг» — модал создания
- Кнопка «Оплатить» на каждом открытом долге — модал оплаты (частичной или полной)

### 4. Partner Settlements (`/finance/partners`)

Два блока:

**Карточки партнёров** — развёрнутая сводка по каждому:
- Вложено в бизнес (contributions)
- Начислено прибыли (profit_accrual)
- Выплачено прибыли (profit_payout)
- Draw / авансы
- Возвращено вложений (reimbursement)
- Итоговый баланс с пояснением (компания должна / партнёр должен)
- 4 кнопки действий: Вклад, Возврат вложений, Draw, Выплата прибыли

**История операций** — таблица всех settlement entries по обоим партнёрам.

Каждая модалка содержит hint-блок, объясняющий смысл операции.

### 5. Closing Periods (`/finance/closing`)

- Выбор периода (month picker)
- Кнопка «Предпросмотр» — показывает расчёт income/expense/profit
- Блок начисления партнёрам (50/50)
- Кнопка «Закрыть период» / «Пересчитать и закрыть» (если уже закрыт)
- Таблица истории закрытых периодов

## Навигация

Tab-навигация (`FinanceNav`) на каждом экране:
- Обзор → Журнал операций → Долги поставщикам → Расчёты с партнёрами → Закрытие периода

## UX-решения

### Различение типов операций с партнёрами

Каждая модалка содержит цветной hint-блок с пояснением:
- **Вклад** (зелёный): деньги партнёра → на счёт компании
- **Возврат вложений** (оранжевый): компания возвращает вложенное (НЕ прибыль)
- **Draw** (жёлтый): аванс до распределения прибыли
- **Выплата прибыли** (синий): фактическая выплата начисленной прибыли

### Баланс партнёра

Формула показана на карточке:
```
баланс = вложения + прибыль − выплаты − draw − возмещения
```
- Положительный → «Компания должна партнёру»
- Отрицательный → «Партнёр должен компании»

### Предпросмотр закрытия

Перед закрытием периода можно увидеть расчёт без фиксации результата.

## Упрощения

- Нет inline-редактирования счетов (только через backend)
- Нет графиков — только таблицы и карточки
- Нет подробных отчётов за период — только итоговые суммы
- Привязка транзакции к заказу (`link_transaction_to_order`) не вынесена в UI (используется через заказы)
- Корректировки (adjustment) не имеют отдельного UI — предполагается использование через backend
